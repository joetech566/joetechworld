🛰️ Basic setup checklist

  1. Secure the dish and point it toward the correct satellite orbital position for your location.
  2. Connect the coaxial cable and select the correct LNB type/frequency.
  3. Set DiSEqC correctly for your switch setup (Off/None only if no switch is used).
  4. Add a valid transponder and watch signal quality while fine-tuning the dish.
  5. Run a scan, save channels, and confirm reception.
